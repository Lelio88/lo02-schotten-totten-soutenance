# Schotten Totten : soutenance 1 (LO02)

Diaporama de la première soutenance du projet LO02 : modélisation UML de Schotten Totten
(diagrammes de classes et de séquence, patrons Singleton, Stratégie, Fabrique et Visiteur).

## Utilisation

- Ouvrir `index.html` (écran public) : flèches, espace ou clic pour avancer, `F` pour le plein écran.
- Touche `P` : ouvre la console présentateur (notes, chronomètre, slide suivante) dans une
  seconde fenêtre à placer sur l'autre écran. Les deux fenêtres se synchronisent.
- Ajouter `?all` à l'adresse affiche toutes les étapes d'un coup (relecture, export PDF).

Fonctionne hors ligne une fois chargé ; sans WebGL ou avec « réduire les animations », les
transitions se replient sur de simples fondus.
